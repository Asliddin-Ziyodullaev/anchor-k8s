# Support

Use [GitHub Issues](https://github.com/anchor-k8s/anchor/issues) for reproducible bugs and feature requests. The issue forms ask for the information needed to investigate.

For usage questions, first check the [README](README.md): it covers setup, multiple kubeconfigs, SSH tunnels, Argo CD and the monitoring tabs. If that doesn't help, open a discussion if GitHub Discussions is enabled, or a clearly labelled question issue.

Before asking, try `npm run demo`: if the problem also happens in demo mode, mention it, as it rules out cluster and permission issues.

Do not post kubeconfigs, tokens, cluster addresses, real logs or other private data. Reduce the problem to the smallest safe example.
